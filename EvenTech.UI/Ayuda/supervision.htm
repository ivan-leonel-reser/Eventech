Supervisión del evento

El supervisor sigue el evento el día que se realiza.

  1. Con el evento LISTO, presionar Iniciar ejecución (en otra fecha que la del evento, el sistema pide confirmarlo). Desde ese momento el personal, el cronograma, las tareas y la reserva quedan congelados; los cobros se siguen admitiendo.
  2. Lo que se aparte del plan se registra como incidencia: tipo, Qué pasó y quién la informó; presionar Registrar.
  3. Cada incidencia se cierra con Resolver, indicando cómo se resolvió.
  4. Con todas las incidencias resueltas, Cerrar evento.
