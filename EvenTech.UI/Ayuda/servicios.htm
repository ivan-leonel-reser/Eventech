EVENTECH

Catálogo de servicios

La sección Servicios administra lo que se puede contratar para un evento (catering, música, decoración, personal…) con su precio unitario.

  1. Presionar Nuevo, completar nombre, descripción y precio, y presionar Guardar.
  2. Para modificar, seleccionar el servicio, cambiar los datos y presionar Guardar.

El nuevo precio rige para las líneas que se agreguen después; las reservas existentes conservan el precio con que se contrataron.
