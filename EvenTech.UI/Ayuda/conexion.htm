Configuración de la conexión

La conexión a la base de datos la deja configurada el instalador. Si al abrir el sistema la base no responde o no tiene el esquema esperado, antes del acceso aparece la pantalla Configuración de conexión.

  1. Elegir la Instancia de SQL Server de la lista (o escribirla) y la Base de datos (EvenTechDB).
  2. Presionar Probar; con Conexión correcta, presionar Guardar: el sistema se reinicia con la conexión nueva.

La conexión se guarda cifrada en el perfil del usuario de Windows. Salir cierra el sistema sin cambiar nada.
